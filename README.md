# BANGLA RAIL LIVE

Native Android starter project for a Bangladesh railway tracking app.

## Current starter features
- Premium dark theme (black, midnight blue, neon blue)
- Jetpack Compose dashboard
- Bottom navigation
- Placeholder screens for Live Map, Trains and Profile
- GitHub Actions workflow to build a debug APK

## Build APK
Push this project to a GitHub repository on the `main` branch. Open **Actions** and select **Build Android APK**. When the workflow finishes, download the `bangla-rail-live-debug-apk` artifact.

## Important
This is the UI and build foundation only. It does not yet contain real train schedules, a map SDK, GPS sharing, a backend, or live railway data. Those will be added in later development phases.
